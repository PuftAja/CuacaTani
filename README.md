# 🌾 CuacaTani

Website informasi cuaca untuk membantu petani dalam memantau kondisi cuaca dan mengelola lahan.

## 📖 Deskripsi

CuacaTani merupakan website yang dikembangkan sebagai proyek UAS Mata Kuliah **Pemrograman Web Lanjutan**.

Website ini menyediakan informasi cuaca berdasarkan lokasi lahan sehingga pengguna dapat merencanakan aktivitas pertanian dengan lebih baik.

## ✨ Fitur

- Login & Register
- Dashboard
- Manajemen Lahan (CRUD)
- Informasi Cuaca
- Prediksi Cuaca 5 Hari
